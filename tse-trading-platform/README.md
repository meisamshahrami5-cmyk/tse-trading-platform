# CryptoAI Pro (TSE Trading Platform)

پلتفرم تحلیل و پیش‌بینی بازار کریپتو (BTC, ETH, BNB, SOL, ADA) با XGBoost

## ✨ ویژگی‌ها

- 🧠 **مدل هوش مصنوعی:** استفاده از XGBoost با 14 ویژگی تکنیکال
- 📊 **داشبورد تعاملی:** نمودارهای زنده با RSI، MACD، Bollinger Bands
- 🎯 **سیگنال هوشمند:** پیش‌بینی روند با درصد اطمینان و مدیریت ریسک
- 💼 **استراتژی فیوچرز:** محاسبه خودکار حد ضرر/سود بر اساس ATR
- 📈 **بک‌تست حرفه‌ای:** ارزیابی عملکرد با Sharpe Ratio و Max Drawdown
- 🌐 **دو رابط کاربری:** نسخه FastAPI + HTML (توصیه شده) و Streamlit
- 🔄 **یکپارچگی کامل:** تمام فایل‌ها از ماژول مشترک اندیکاتورها استفاده می‌کنند

## 🚀 نصب و راه‌اندازی

```bash
pip install -r requirements.txt
```

## 🛠️ معماری پروژه

```
tse-trading-platform/
├── main.py                  # نقطه ورود اصلی (دریافت داده → آموزش مدل)
├── server.py                # سرور FastAPI + API endpoints
├── app.py                   # رابط کاربری Streamlit (قدیمی)
├── live_signal.py           # اسکریپت سیگنال زنده در خط فرمان
├── backtest.py              # اسکریپت بک‌تست مستقل
├── src/
│   ├── data_collection/     # دریافت و پردازش داده‌های خام
│   ├── indicators/          # ماژول مشترک اندیکاتورها و مهندسی ویژگی
│   ├── ml/                  # آموزش و ارزیابی مدل‌های یادگیری ماشین
│   └── utils/               # توابع کمکی عمومی
├── models/                  # مدل‌های آموزش‌دیده (joblib)
├── data/
│   ├── raw/                 # داده‌های خام OHLCV
│   ├── processed/           # داده‌های تمیز شده
│   └── features/            # داده‌های دارای ویژگی‌های تکنیکال
└── web/                     # رابط کاربری HTML/JS
```

### 🔧 یکپارچگی کد

تمام فایل‌های پروژه (`app.py`, `server.py`, `live_signal.py`) از ماژول مشترک `src.indicators` برای محاسبه اندیکاتورهای تکنیکال استفاده می‌کنند. این طراحی:

- ✅ از تکرار کد جلوگیری می‌کند
- ✅ ناهماهنگی بین آموزش و پیش‌بینی را حذف می‌کند
- ✅ نگهداری و به‌روزرسانی الگوریتم‌ها را آسان می‌کند

## 🌐 اجرای رابط وب (HTML)

```bash
python server.py
```

یا روی ویندوز فایل `run_web.bat` را دوبار کلیک کنید. مرورگر خودکار روی `http://127.0.0.1:8000` باز می‌شود.

- `server.py` — سرور FastAPI: مدل‌های `models/*.joblib` را لود می‌کند و APIهای `/api/dashboard`، `/api/signal`، `/api/backtest` را می‌دهد
- `web/index.html` — رابط کاربری تک‌فایلی (راست‌چین، فارسی، نمودارهای Plotly)
- اگر اینترنت / Yahoo Finance در دسترس نباشد، از داده‌های `data/raw` استفاده می‌شود و در رابط با نشان «آفلاین» مشخص است
- متغیرهای اختیاری: `PORT=8000`، `HOST=127.0.0.1`، `NO_BROWSER=1`
